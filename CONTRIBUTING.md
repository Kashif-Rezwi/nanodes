# Contributing to Nanodes

Nanodes is currently a planning-stage project. There is no library implementation or npm release yet.

Use [docs/roadmap.md](docs/roadmap.md) as the single source of truth. Work follows **Plan → Implement → Review**, one phase at a time.

1. Check the current phase and discuss material scope or API changes before implementation.
2. Make the smallest focused change that meets its acceptance criteria.
3. Preserve the portfolio reference behavior and document deliberate differences.
4. Add verification appropriate to the change; distinguish measured results from assumptions.
5. Present the result for maintainer review and record evidence in the roadmap before beginning another phase.

Keep runtime and framework peer dependencies at zero. Development-only tooling is acceptable when it supports an actual check or build.

Do not include portfolio contact details, unrelated page content, credentials, or third-party assets without the necessary rights and notices.

Installation and development commands will be documented when real build and test tooling exists.
